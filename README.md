# E-commerce Sales Data Pipeline

Data cleaning and analysis pipeline for online retail transaction data (2010-2011).

## What this project does
- Cleans raw transaction data (removes returns, invalid prices)
- Converts dates and engineers new features (TotalPrice, Month/Year)
- Analyzes revenue trends by month, top products, and top countries
- Generates visualizations for business insights

## Tools used
Python, Pandas, Matplotlib

## Key findings
- Revenue peaked in November 2011 (holiday shopping season)
- UK generates ~90% of total revenue
- Top products include gift/decor items and postage charges

## Files
- `exploration.ipynb` — full analysis notebook
- `OnlineRetail.csv` — source dataset (UCI Online Retail Dataset)
